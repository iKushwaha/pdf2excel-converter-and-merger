Frequently asked

Is my data uploaded anywhere?

PDFs are uploaded to the server URL you configure above. That server runs on your own machine or infrastructure — nothing goes to a third party.

How do I run the server?

Clone the repo, install dependencies, and run python -m pdf2xlsx.web.server. The server starts on port 8000 by default.

Which formats are supported?

PDF input, .xlsx output. Ruled tables, free text, and embedded images are all handled.

What about scanned PDFs?

Scanned pages are embedded as pictures with a clear notice. OCR is not bundled, so run OCR on the PDF first if you need searchable text.
